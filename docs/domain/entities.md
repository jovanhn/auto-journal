# Entities

All tables live in the `autojournal` PostgreSQL schema. Each table is owned (written) by exactly one module.

## Project — module `projects`, table `project`

| Field         | Type          | Rules                                                     |
| ------------- | ------------- | --------------------------------------------------------- |
| `id`          | UUID          | Generated by the application                              |
| `name`        | text (1–100)  | Required, trimmed, unique case-insensitive (`LOWER(name)` unique index) |
| `description` | text (≤ 2000) | Optional; blank is stored as null                         |
| `created_at`  | timestamptz   | Set on creation                                           |

## Task — module `tasks`, table `task`

| Field            | Type          | Rules                                                          |
| ---------------- | ------------- | -------------------------------------------------------------- |
| `id`             | UUID          | Generated by the application                                   |
| `project_id`     | UUID          | Required; FK → `project.id`; referenced by ID only (no JPA relation) |
| `title`          | text (1–200)  | Required, trimmed                                              |
| `status`         | `OPEN`\|`DONE` | New tasks are `OPEN`                                          |
| `created_at`     | timestamptz   | Set on creation                                                |
| `parent_task_id` | UUID, optional | **Planned** (specs/subtasks.md): the parent task, same project. Not in the schema yet. |

## Relationships

- A project has zero or more tasks; a task belongs to exactly one project.
- *(Planned)* A task has zero or more subtasks; a subtask has at most one parent task.
